1. 截下输入框右侧那颗「浮窗」按钮，存为 `01-composer-button.png` 放进本目录。
2. 打开根目录的 `README.md`，找到「效果截图」一节里
   `> **TODO**：还剩一张——输入框右侧的「浮窗」按钮（触发入口）。` 那条引用块，
   按现有写法加一段（`**加粗小标题**` + 一行说明 + `![alt](docs/assets/01-composer-button.png)`），
   然后把那条 TODO 整块删掉。
3. 提交。

## 截图注意事项

- **只截插件自己的界面。** 悬浮窗里可能有你的对话内容，截之前先确认没有不该公开的信息。
  已入库的四张里，对话内容只有模型对「你好」的通用回复，不含私人信息；
  设置页两张的缓存读数分别是 `4 B` 与 `381.5 KB`，不涉及路径或会话 ID。
- **不要截到 `window/webview-data/` 相关内容**，那里面有认证 cookie。
- 浅色外观也来一张会更有说服力——目前已入库的四张都是深色。
- 窗口是圆角无边框的，截近景时可以直接用截图工具框选窗口区域；
  截整屏时保持浮窗**部分覆盖**在 DSH 主窗口之上，一眼就能看出「它是独立窗口」这一点。
