## 补图步骤

1. 按下面的文件名把图片放进本目录：

   | 文件名 | 内容 |
   |---|---|
   | `01-composer-button.png` | 输入框右侧的「浮窗」按钮 |
   | `02-float-window.png` | 悬浮窗本体（压在其他应用之上） |
   | `03-settings-page.png` | 设置 → 悬浮窗 的设置页 |
   | `04-title-bar.png` | 原生标题栏的五颗按钮 |

2. 打开根目录的 `README.md`，找到「效果截图」一节的 `<!--` 与 `-->` 两行，
   **把它们删掉**（中间的正文已经写好，与上面的文件名一一对应，不需要改）。
3. 提交。

## 截图注意事项

- **只截插件自己的界面。** 悬浮窗里可能有你的对话内容，截之前先确认没有不该公开的信息。
- **不要截到 `window/webview-data/` 相关内容**，那里面有认证 cookie。
- 深色 / 浅色两种外观各来一张会更有说服力（README 里预留的是深色为主）。
- 窗口是圆角无边框的，截图时可以直接用截图工具框选窗口区域。
